================================================================================
4. DOWNLOADED ON FIRST USE, NOT SHIPPED
================================================================================

None of these is in a package. Each is fetched the first time it is
wanted, into the user's cache or model store, with a note of its
license written beside it there.

  The AI models (denoise, masks, people, generative remove), each
    under its own license, which greycard shows before the download.
  The lensfun lens database (https://lensfun.github.io), CC BY-SA 3.0.
  Microsoft's CPU-only ONNX Runtime, on Windows ARM64 and on an x86-64
    processor the shipped runtime cannot run on: MIT License, its
    LICENSE kept beside it.
