# Brazilian Portuguese (pt_BR) glossary for greycard's window

This is the glossary of a draft translation that no native speaker has
read yet. Corrections to it and to the catalog are welcome.

Source of terms: the Brazilian Portuguese Lightroom Classic (LR), Capture
One (C1), and darktable (dt). Where they differ, LR wins and the
alternative is noted.

## Conventions

- **Register:** Brazilian, never European: arquivo (not ficheiro), tela
  (not ecrã), salvar (not guardar), excluir (not eliminar), baixar (not
  descarregar), lixeira, usuário (not utilizador), "registrar" etc.
- **Commands** are infinitives: Exportar, Cortar, Salvar, Desfazer.
- **Address:** impersonal where it reads well; "você" when a sentence
  needs a subject. Never "tu", never "o senhor".
- **Case:** sentence case, as the source. A source heading in ALL CAPS
  stays ALL CAPS (LUZ, COR, CORTE).
- **Keys:** Shift, Ctrl, Alt, Tab, Esc, Enter, Space as ABNT2 keyboards
  print them (they print the English names); never translated. The
  search's own words (camera:, iso>=) stay.
- **Loanwords kept:** raw, JPEG, TIFF, PNG, HDR, ICC, XMP, backup (noun,
  and "fazer backup"), EV, mired, program and site names.
- **Frame** (a photo in the library) is **foto** (feminine), so its
  adjectives agree: escolhida, rejeitada, classificada. **Picture** is
  imagem where the source sets it against frame, else foto.
- **Plurals:** nplurals=2; plural=(n > 1), so 0 and 1 take the singular.
- **Ellipsis:** keep the source's "..." or "…" exactly.
- **Short:** buttons, tabs, and rows are narrow; pick the shorter of two
  equally clear words.

## Narrow places and words kept apart

Where a narrow button, row, or column clipped the first choice, where
two words had to be told apart, or where the literal word misled, the
catalog uses another.

| English | Instead of | Used | Why |
| --- | --- | --- | --- |
| Dehaze (slider and its entry) | Remover névoa | Desembaçar | "Remover n..." clipped in the slider column; Desembaçar is the common BR word |
| Heal / Clone / Fill (retouch buttons, one entry each) | Recuperar / Clonar / Preencher | Curar / Clone / Tapar | three equal buttons with icons hold about five letters; alt Recuperar / Clonar / Preencher where there is room |
| Cull (the Loupe's 40 px mode button) | Triagem | Triar | fixed 40 px; prose keeps Triagem |
| Preset (the export sheet's 68 px row) | Predefinição | Preset | the loanword the glossary allowed; headings keep PREDEFINIÇÕES |
| Watermark (68 px row) | Marca-d'água | Marca | the row's options say Texto / Imagem |
| Soft proof (Editing row, 68 px) | Prova de tela | Prova | heading keeps PROVA DE TELA |
| Scroll bars / Scroll bar size | Barras de rolagem / Tamanho das barras | Rolagem / Espessura | row labels clipped |
| Cell size | Tamanho da célula | Célula | 68 px row |
| Edits go (sidecars row) | Edições ficam | Salvar em | 68 px row |
| Dark grey / Mid grey (canvas) | Cinza-escuro / Cinza médio | Grafite / Cinza | five options in one row ran together |
| Red / cyan, Blue / yellow (manual CA sliders) | Vermelho / ciano, Azul / amarelo | Vermelho, Azul | slider label column |
| Fit this camera's look... | Ajustar o visual desta câmera... | Ajustar à câmera... | the Look section's half-width button |
| Check now | Verificar agora | Verificar | 96 px button |
