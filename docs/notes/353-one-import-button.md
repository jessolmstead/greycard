# §353. One Import button (2026-10-18)

The left pane had two full-width buttons, Import... and Import a
Lightroom catalog..., and at the pane's 240 px the second truncated
to "Import a Lightroom catal...". There are three ways things come
into greycard, and they are three different verbs on one word: a
card or folder brings pictures in, by copy with a rename and a
verified backup or in place as a root (§347); a Lightroom catalog
brings pictures and edits at once, its folders as roots and its
ratings, edits and collections as ours (§337); RawTherapee profiles
bring edits only, for a folder already open (§340). Two buttons
would become four.

So there is one Import... button, and a click opens a menu where the
two buttons were: From a card or folder..., and A Lightroom
catalog.... It is the same menu the Help button uses, so nothing new
is learned or built. The running states stay on the button's face,
since they are state the user must see without opening anything:
Stop import or Stopping... while a card import runs, a click
stopping it with no menu, and Importing the catalog... while a
catalog writes, the button waiting. A card import and a catalog
import can no longer be started over each other, which the two
buttons allowed and which was never a good idea.

Not a split button: there is no single default import that deserves
the main half, since a card import and a catalog import are equally
rare and equally deliberate. Not a three-dot beside Import, which
would read as more options for that import. The RawTherapee offer,
made when a folder opens, is a candidate for a third entry, so that
someone who declined the offer can come back to it; left for when it
is asked for.
